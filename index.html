StepRing

A personal macOS menu bar app. Not distributed; used only by its author.

Privacy policy

StepRing reads the signed-in user's own daily step count from the Google Health API (read-only scope googlehealth.activity_and_fitness.readonly) and shows it in the macOS menu bar.

  • Data is read only to display it on the user's own Mac. Nothing is written back to Google.
  • Step counts and the sign-in token stay on that Mac (app preferences and the macOS Keychain). Nothing is sent to any server other than Google's own APIs.
  • No data is sold, shared, transferred to third parties, or used for advertising or AI training.
  • Signing out in the app revokes access and deletes the stored token. Access can also be removed at myaccount.google.com/permissions.

StepRing's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
